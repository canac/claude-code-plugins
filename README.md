# claude-code-plugins

Claude Code plugins

## Install

```sh
claude plugin marketplace add canac/claude-code-plugins
claude plugin install ui-testing@canac
```

## Plugins

- `contradict`: attack a plan with parallel adversarial subagents
- `open-here`: band with buttons to open the session's directory in a cmux tab, VS Code or Zed
- `trim-comments`: trim verbose comments on the current branch
- `ui-testing`: test web UIs in a dedicated Chrome over CDP, with per-session proxy support
